# Thesis Tools

Utilities added for thesis-specific figures and clarifications.

Scripts:

- `plot_training_durations.py`
  - compares training duration across `YOLOv8n`, `YOLOv8l`, and `Faster R-CNN`
- `plot_best_viewpoints_72.py`
  - shows all 72 exact viewpoints per object and highlights the best-by-mean viewpoint
- `visualize_example_bboxes.py`
  - creates thesis-ready example images with ground-truth and optional YOLO predictions

Method note:

- `HEATMAP_METHOD_S0_M4.md`
  - explains how the current `S0_M4` heatmaps are calculated
