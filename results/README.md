# Results

This directory contains the figures, tables, and analysis reports associated with the thesis.

| Directory | Description |
| --- | --- |
| `figures/` | Figures generated for the thesis and appendix. |
| `tables/` | CSV files containing quantitative results and summary statistics. |
| `reports/` | Reports documenting the analyses and their results. |
| `recomputed/` | Default output directory for rerunning analysis scripts. |
| `intermediate/` | Optional directory for intermediate files, such as cached predictions and ground-truth annotations. |

The repository retains the main figures, summary tables, and reports. Large intermediate outputs may need to be regenerated or restored separately.
