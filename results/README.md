# Results

This folder stores the result artifacts used in the thesis.

| Folder | Contents |
| --- | --- |
| `figures` | Rendered thesis and appendix figures |
| `tables` | CSV summaries used for result tables and quantitative comparisons |
| `reports` | Markdown reports written during analysis |
| `recomputed` | Default output location for rerunning scripts |
| `intermediate` | Optional location for restored large intermediate files such as prediction JSONs |

The final figures and summary tables are kept here even when large intermediate model outputs are omitted.
